# i18n Conventions

## Locales

| Locale | Resource directory |
|--------|-------------------|
| English (default) | `values/` |
| Portuguese (Brazil) | `values-pt-rBR/` |

## Layer Language Rules

| Layer | Language |
|-------|----------|
| Code (classes, functions, enums) | English |
| Commits and PRs | English |
| Technical documentation | English |
| User-visible strings | i18n keys |

## Key Naming

Pattern: `feature_component_description` (snake_case)

```
exercise_library_title
active_session_complete_set
error_duplicate_exercise_name
muscle_group_chest
```

## Rules

- Never hardcode user-visible strings in Composables
- Enum display uses mapper → string resource, not `enum.name`
- Dates and numbers use `Locale`-aware APIs
- Weight display respects `weight_unit_display` preference (stored kg internally)

## Minimum Key Set (v1)

| Key | EN | PT-BR |
|-----|----|-------|
| `app_name` | OpenFitness | OpenFitness |
| `exercise_library_title` | Exercises | Exercícios |
| `history_empty_title` | No workouts yet | Nenhum treino ainda |

Full key list to be maintained alongside feature implementation.
