# Value Object — SessionId

| Type | `@JvmInline value class` wrapping `UUID` |
|------|------------------------------------------|
| **Module** | `com.openfitness.domain.valueobject.SessionId` |

## Invariants

- Valid UUID v4
- Generated by domain on session creation — never by database auto-increment

## Factory

```kotlin
@JvmInline
value class SessionId(val value: UUID) {
    companion object {
        fun generate(): SessionId = SessionId(UUID.randomUUID())
        fun fromString(raw: String): SessionId
    }
}
```

## Usage

- Identity for `WorkoutSession`
- Reference in `SetLog`, `PersonalRecord`
